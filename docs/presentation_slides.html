Problem Statement & Objectives
Background

⚠️ Core Recommender Obstacles

  • Extreme Sparsity: Users interact with <2% of available movies, causing collaborative neighbor discovery to falter.
  • Cold-Start Failure: Collaborative filtering cannot score items for new users with zero history.
  • Popularity Bias: Heuristic models over-recommend blockbusters, creating monoculture echo chambers.

🎯 Key Project Deliverables

  • Multi-Model Pipeline: Implement User-CF, Item-CF, SVD, Content-based TF-IDF, and PyTorch NCF.
  • Weighted Hybrid: Blend models via per-user z-scores to surpass all constituent algorithms.
  • Interactive Deployment: Launch a Streamlit web app with cold-start fallback and live feedback capture.

End-to-End System Architecture
Engineering Design

Autonomous squad modules communicating strictly via standard top-10 contracts (userId, movieId, rank, score):

MovieLens Data → Chronological LOO Split + 80/20 Random Split
  └→ User-CF (Cosine Sim on Mean-Centered Ratings)
  └→ Item-CF (Adjusted Cosine + Co-rater Shrinkage)
  └→ SVD (100 Latent Factors + Biases)
  └→ Content (TF-IDF on Genres + Tags) → Cold-Start Fallback
  └→ PyTorch NCF (NeuMF Dual-Branch Architecture)
        ↓
Weighted Hybrid (Per-User Z-Score Normalization) → Streamlit Web App + Feedback

Collaborative Filtering & Latent Factors
Algorithms

👥 User-Based CF (Cosine)

  • Calculates cosine similarity on mean-centered ratings: $R^c = (R - \bar{r}_u) \cdot B$.
  • Keeps top $k=50$ positive neighbors.
  • Shrinkage $\beta=5.0$ dampens small overlaps.
  • Yields high personal peer affinity (Recall@10 = 0.0909).

🎬 Item-Based CF & SVD Matrix Fact.

  • Item-CF: Adjusted cosine similarity with co-rater shrinkage ($\lambda_{\text{sim}}=10.0$); stable neighborhoods.
  • SVD: 100 latent factors with user/item biases learned via SGD over 20 epochs.
  • SVD achieved best RMSE: 0.8831 on 80/20 test split.

Content-Based & Weighted Hybrid (Core)
Core Deliverable

🏷️ Content-Based (TF-IDF)

  • Sublinear TF-IDF vectorizer over genres + tags.
  • User profile = rating-weighted centroid vector.
  • Highest catalog coverage (21.68%); acts as cold-start fallback.

⭐ Weighted Hybrid Engine

  • Standardizes scores via per-user z-scores: $Z_m(u,i) = \frac{S_m - \mu_m}{\sigma_m}$.
  • Grid search on validation split ($N_{\text{val}}=5$) avoids test leakage.
  • Optimal weights: w_user = 0.60, w_item = 0.40.
  • Highest Recall@10 (0.0964) and NDCG@10 (0.0521).

Deep Learning: Neural Collaborative Filtering
PyTorch NCF

🧠 NeuMF Architecture

  • GMF Branch: Linear element-wise embedding product ($\mathbf{p}_u \odot \mathbf{q}_i$).
  • MLP Branch: 3-layer dense feedforward network learning non-linear feature interactions.
  • Output: Projected via sigmoid layer with Binary Cross-Entropy loss on implicit interactions.

📈 Hyperparameter Tuning Results

  • Swept 7 configurations across dimensions and dropout.
  • Best Architecture: dim=16, layers (32, 16, 8), dropout=0.1.
  • Prevented overfitting on sparse data; achieved Val Recall = 0.0824 at epoch 16.
  • Final test Recall@10 = 0.0744, NDCG@10 = 0.0377.

Evaluation Protocol & Metrics
Methodology
  • Chronological Leave-One-Out (LOO): Evaluates whether the single held-out latest interaction appears in top-10 recommendations.
  • Relevance Threshold ($\ge 4.0$): Evaluated across 363 relevant users. Recommending disliked movies is penalized as a miss.
  • Metrics Formulations:
    • Recall@10: Fraction of relevant held-out items successfully recovered in top-10.
    • NDCG@10: Evaluates ranking position using logarithmic discount: $\frac{1}{\log_2(\text{rank} + 1)}$.
    • RMSE: Evaluated on independent 80/20 random split ($N=20,168$) for rating predictors.
    • Catalog Coverage: Percentage of total 9,742 movies recommended across all users.
